# Self-host RSSerpent

Start the official image and open [port 8000](http://localhost:8000/).

```sh
docker run --rm -p 8000:8000 ghcr.io/rsserpent-rev/rsserpent:main
```

This starts the core. To add feeds, [deploy with a plugin configuration](plugin.md).

If you want to use a hosted service, open the [official instance](https://rsserpent.imciel.com/).
